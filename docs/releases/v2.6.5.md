# v2.6.5 — Claude Sonnet 5.5 for synthesis and escalation

Patch release covering everything since **v2.6.4**. This is the release for #86.

| Commit | PR | Summary |
|---|---|---|
| `8873af4` | #86 | Use Claude Sonnet 5.5 for final synthesis and abstract escalation |

## Changes

- **Final synthesis:** `SYNTHESIS_MODEL` defaults to `claude-sonnet-5-5` on the Anthropic Messages API. That id is the final opinion, the merge, and follow-ups. Gemini and Haiku values are still ignored.
- **Abstract escalation:** `ABSTRACT_ESCALATION_MODEL` defaults to `claude-sonnet-5-5`. The release workflow still sets `ABSTRACTION_ESCALATION_ENABLED=false` on the API, so production does not make those re-reads.
- **OpenRouter:** `claude-sonnet-5-5` maps to `anthropic/claude-sonnet-5.5`. A plain `anthropic/` prefix would send a hyphenated id that is not on the OpenRouter model list.
- **Unchanged:** document abstracts and partial synthesis stay on `gemini-3.1-flash-lite`. The release workflow still does not set `SYNTHESIS_MODEL` or `ABSTRACT_ESCALATION_MODEL`, so Cloud Run uses these code defaults.

## Tests

- Assertions that pin the final-synthesis and escalation model ids now expect `claude-sonnet-5-5`
- OpenRouter request mapping checks the dotted Sonnet 5.5 slug
- Full suite green
