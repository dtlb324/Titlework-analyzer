## Changes

- **Truncated Haiku output fixed:** the OCR comparison lab reused production's 2,000-token abstraction limit, which cut off Claude Haiku 5.5 (whose adaptive thinking tokens count against the same limit) and multi-instrument uploads. The UI reported "output may be truncated by the token limit".
- **Shared lab limit:** all three models now use one limit, 8,000 by default. Set `OCR_COMPARE_MAX_TOKENS` (512–8192) to change it; invalid values fall back to the default. 8192 is the non-streaming Anthropic ceiling. The limit was raised for every model, not only Haiku, because the page requires equal limits across models.
- **Cost:** the limit is a ceiling, so short outputs cost the same; long outputs cost more.
- **Production unchanged:** abstraction limits used by title jobs are not affected.

## Verification and rollout

- `npm test` passed, including new tests for the 8000 default, the environment override, and invalid-value fallback.
- No live Haiku run was made before release. If output is still truncated, the downloaded report's `stopReason` and `usage` show whether thinking used the budget.
- No environment variable change is required. The API service keeps `OCR_COMPARE_ENABLED=true` and `ANTHROPIC_API_KEY`.
