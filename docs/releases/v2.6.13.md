## Changes

- **Haiku effort:** the OCR comparison lab now calls `claude-haiku-5-5` with `output_config.effort` set to `medium`. The previous lab setting was `low`. Adaptive thinking is unchanged.
- **What this is for:** a new comparison can show whether title-field accuracy improves at the higher effort.
- **Shown in the lab:** the Haiku column reports `adaptive, effort medium`.
- **Production unchanged:** abstraction and synthesis calls still do not set `effort`.
- **Docs:** `docs/ocr-comparison-lab.md` and `AGENTS.md` describe the medium setting.
