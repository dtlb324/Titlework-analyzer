## Changes

- **Several files per run:** the OCR comparison page accepts up to 10 PDF, PNG, JPEG, or WebP files at once. Files run one at a time in the order selected, with the three models in parallel for each file.
- **Per-file review:** a Files table shows pages, status, model failures, and estimated cost for each file, with a View button to open its three outputs and field differences.
- **Failure handling:** a file that cannot be rendered or validated is listed and skipped. A request-level failure stops the remaining files, keeps finished results, and is never retried automatically.
- **Report:** the downloaded JSON report now holds a `files` array with one entry per finished file.
- **Limits:** the 10-page and 12,000,000-byte limits apply to each file separately. Each file makes three billable model calls.
- **Docs:** `docs/ocr-comparison-lab.md` describes the multi-file flow.

## Verification and rollout
