## Bug fixes

- **Canceled jobs ran the final merge anyway:** a cancel landing after the last segment completed still triggered the (billable) Sonnet merge and persisted a result for a canceled job. The segment loop already broke on cancel, but the merge gate never checked. `processSynthesisJob` now re-checks job status before both merge branches (full + partial-failure degraded) and skips merge + result save when canceled.

## Tests

- New regression: "canceled jobs skip the final merge and save no result"
