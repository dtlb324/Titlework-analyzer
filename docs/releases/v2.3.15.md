# v2.3.15 — Job UI cleanup and cancel reset fix

Patch release: removes confusing manual workflow buttons on the job page, auto-continues stalled server work while you watch a job, and fixes **Cancel job** leaving stale home-screen state.

---

## Highlights

- **Removed Continue abstraction / Continue synthesis buttons** — stall recovery now runs automatically from the job poller (same ~4s threshold as the main Analyze flow)
- **Cancel job resets home cleanly** — clears the keep-tab-open notice, prior title opinion, and upload UI; navigates to `#/`; aborts in-flight analyze loops so a canceled run cannot republish results
- **New runs clear stale home results** — starting Analyze clears any previous report and info banner first

---

## Job page

While a job is `abstracting`, `queued`, `planning`, or `synthesizing`, the job poller checks abstraction/synthesis status and POSTs `/abstraction/process` or `/synthesis/process` when progress stalls — no manual kick required.

**Cancel job** is unchanged and remains available for in-progress jobs.

### Files

- `public/index.html` — `maybeKickStalledJobWorkflow`, `handleJobCanceled`, `prepareHomeForAnalysisRun`, removed manual continue buttons
- `test/app.test.js` — poller auto-continue and cancel-reset coverage
