## Bug fixes

- **Auth and rate limits:** unauthenticated `/api/*` requests are rejected before the body buffer; job-password failures keep a ~500ms delay and 5-strike throttle; GET `/api/jobs/*` is rate-limited. Client IP uses the rightmost `X-Forwarded-For` hop. Shared limiter objects live in GCS with a 1s in-process cache; non-412 GCS errors fail closed (503) instead of falling back to per-instance memory.
- **Hybrid PDFs:** mixed text/image PDFs use text plus sparse visual coverage instead of dropping sparse pages or sending the whole document through visual OCR.
- **Pipeline:** multi-chunk batch fallback can re-claim the same worker’s live lease without burning an extra attempt; reclaim cap stops poison loops. A saved result row (including an empty failed opinion) counts as `hasResult`. Signed PUT sizes are bounded.
