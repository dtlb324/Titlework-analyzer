## Changes

### Job state, concurrency, and billing protection (#159, #161, #162, #164)

- **Prevent re-billing and data loss on finished/canceled jobs:** synthesis start/process/enqueue/plan refuse `complete` jobs (`409`); chunk claim, lease renewal, abstract save, and retry SQL refuse `complete` and `canceled` jobs; segment/merge claims require a status valid for every result transition and verify no result already exists for the plan; `saveJobResult` is a single guarded statement; split and plan transactions lock the parent row first.
- **Serialize mutations and optimistic status guards:** serialize job mutations across endpoints, enforce optimistic `AND status = ...` guards in `updateJob`, `createDocument`, and `finalizeUploads` (allowing duplicate same-status transitions without spurious `409`s), and disallow `status: canceled` via `PATCH /api/jobs/:id` in favor of `POST /cancel`.
- **Upload finalization gate:** refuse adding chunks or moving chunks off `uploaded` after uploads are finalized (`409`); upload split-PDF child files before atomic DB insertion.
- **Worker reliability:** list only runnable statuses (`ready`, `queued`, `planning`, `abstracting`) and include degraded multi-segment jobs with failed segments; stop hot-looping on error/no-progress batches; respect shutdown signals and drain deadlines; clear `ensureSchema` cached promise on rejection.

### Synthesis and model calls (#159, #161, #162, #164)

- **Single-pass splits and recovery:** run split single-pass opinion halves on `partialConfig` (Gemini) and fail closed after split/repair validation failures or errors inside paid splits (`paid_split_failed`); keep `keep_halves` segments whole instead of truncating at the partial cap.
- **Merge compaction and streaming:** fall back to uncompacted segments on failed/invalid compaction with `merge_compaction_skipped` and route oversized merges to the pairwise merge tree; keep valid streamed previews on save failure so the next pass persists without re-billing; isolate degraded previews; renew merge leases during final merges; scope follow-up history to the current opinion.
- **OpenRouter and error classification:** support `MODEL_PROVIDER=openrouter` and slash model IDs in synthesis setup, model resolution, and streaming; map versioned Claude IDs to dotted OpenRouter slugs; treat missing API key, `401`, and `403` as non-retryable `auth_error` without fanning out batches; preserve transient Files API errors for retries and delete unused Gemini file uploads.
- **Encrypted PDFs:** refuse to subset or split owner-locked encrypted PDFs with `pdf-lib` instead of producing blank pages.

### Rate limiting, request handling, and security (#159, #161, #162, #164)

- **Shared GCS rate limiter:** flush buffered counts on TTL expiry, isolate expired windows, wrap refresh errors in `SharedRateLimitError`, pin object `generation` before reading (`readOpsJson`), and share one GCS `Storage` client per process.
- **Request validation and server hardening:** reject JSON primitives/arrays (`400`), malformed percent-encoding, `?path=` query overrides, integer overflows (`INT4`) and non-integer types (`booleans`/`arrays`/blank strings), and deep nested payload scans (iterative `hasRawPayloadFields`); stop empty probes from burning password lockout strikes; handle `HEAD` requests and client stream aborts cleanly.

### Frontend and UI (#159, #161, #162, #164)

- **Job view and polling:** refresh `#view-job` cleanly after run completion/failure without holding the run open, kick stalled unplanned `synthesizing` jobs, end polls on canceled/terminal jobs, guard double submits and overlapping poll ticks, and display failed documents and run notices on `#view-job`.
- **Resilience and export:** disable high-DPI re-read on `complete` jobs, warn before unload during active re-reads, preserve failed-save browser opinions on screen, never retry `401` toward the 5-strike lockout, prune 24h local checkpoints, infer MIME types by extension when needed (e.g., `.csv`), raise `MAX_TOTAL_DOCUMENTS` to `2000`, and fix PDF export arrows and multi-page notice wrapping.
