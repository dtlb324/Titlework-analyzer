# v2.6.18 — Synthesis recovery, bug-hunt fixes, and Node 26

Patch release covering every commit since v2.6.17: PRs #115 through #125 (except the closed #124), one direct commit, and the release metadata commit.

## Included changes

- Renew segment leases before every paid call, count the usage of the truncated original call, and copy single-pass warnings into the result as `segment_1:<warning>` (#125). The renewal SQL was also run on PGlite (Postgres 18.6): it renews only a `processing` row held by the same worker.
- Keep the paid halves when a nested recombine truncates (#123).
- Recover a truncated recombine instead of discarding the paid halves: keep the halves on multi-segment plans, and allow one larger retry on single-pass plans (#122).
- Fix 18 reproduced bugs across jobs, synthesis, the browser app, and the OCR lab (#121).
- Send `anthropic-version: 2026-10-21` on direct Anthropic requests (#118).
- Move to Node 26 (`engines.node` 26.x), then pin 26.12.1 in CI, the release workflow, and the Docker image (#117, #119).
- Dependencies: `unpdf` 1.8.1 → 1.9.0 → 2.0.1 (#116, #120). Dependabot version updates are now grouped into one monthly PR (#115).
- `docs/.DS_Store` was committed directly to Main (5c6e0ab). It has no runtime effect.
- The release metadata commit updates `package.json`, both root lockfile versions, and these notes to 2.6.18.

## Rollout

- No environment variable change is required.
- The runtime image is now Node 26.12.1.
- The release workflow deploys the worker and API from one immutable image digest, verifies version and service parity, and creates the GitHub Release. The published release lists the complete commit range.
