## Bug fixes

- **"Synthesize with warnings" never started synthesis:** mixed abstraction leaves the job at `partial_failed` until the landman chooses to synthesize anyway. Enqueue planned segments but left that status in place, so the worker (which only drains `synthesizing` jobs) and the UI poller (which treats `partial_failed` as terminal) never picked it up. `enqueueSynthesisJob` now moves those jobs to `synthesizing` when no opinion is saved yet. A second click on a job that already has a partial opinion leaves both status and opinion alone.
- **Abstraction rollup could un-complete a finished job:** refreshing chunk counts rewrote `complete` back to `synthesizing` whenever every chunk had succeeded. A later rollup hid the saved opinion, because the UI only fetches `/result` for `complete` / `partial_failed`. SQL and the in-memory rollup now keep `complete` when no pending, processing, or retry-wait chunk work remains.

## Tests
