## Changes

### Security and reliability (#144)

- Restore queue admission limits, bound input preparation and cache lifetime, and wait for sibling preparation tasks before fallback.
- Harden standalone ingress identity handling and update the XML parser dependency.

### PDF libraries (#145)

- Serve pinned jsPDF and pdf-lib bundles from an explicit local vendor allowlist, with integrity checks and no external CDN requirement.
- Update browser audit probes and vendor tests for offline operation.

### Release metadata

- Update the package and root lockfile versions to 2.6.23.
