# v2.3.12 — Synthesis speed Phase 2 (stream final opinion)

Production release for **Phase 2 perceived-latency optimization**: the final Sonnet merge streams text to the browser while generation continues server-side. Builds on v2.3.11 Phase 1 (batch limit + fallback visibility).

**Operating mode unchanged:** browser tab open, background worker off, Opus audit off.

---

## Highlights

- **`SYNTHESIS_STREAM_ENABLED=true`** on API deploy — final Sonnet merge uses Anthropic streaming
- **`GET /api/jobs/:id/synthesis/preview`** — poll buffer `{ text, complete, bytesReceived }` during merge
- **UI streaming preview** in the progress card while `mergeInProgress`
- **Validation unchanged** — preview is ephemeral; `job_results` is written only after `validateFinalOpinion` passes

---

## Phase 2.1 — Stream final merge

### Problem
After all Gemini partial segments finish, users waited on a blank screen while Sonnet generated the full title opinion (often 30–90+ seconds).

### Change
When `SYNTHESIS_STREAM_ENABLED=true` and the server holds the merge lease:

1. Anthropic Messages API is called with `stream: true`
2. Text deltas are buffered in Postgres (`analysis_jobs.synthesis_preview_*` columns)
3. The browser polls `/synthesis/preview` during `mergeInProgress` and renders a draft opinion card
4. On stream completion, `validateFinalOpinion` runs on the full buffer
5. Valid opinions are saved via `saveJobResult`; invalid previews are discarded (not persisted as final)

Partial segment synthesis (Gemini) and tree-merge intermediate steps remain non-streaming.

### Files
- `api/_lib/anthropic-stream.js` — SSE parser
- `api/_lib/model-client.js` — `invokeAnthropicModelStream()`
- `api/_lib/synthesis.js` — preview writer, `synthesisStreamEnabled()`, merge streaming
- `api/_lib/jobs.js` — preview columns + store methods
- `api/jobs/[...path].js` — preview route
- `public/index.html` — preview UI during `pollServerSynthesis`

## Production configuration (API service)

| Variable | Value | Notes |
|----------|-------|-------|
| `OPUS_AUDIT_ENABLED` | `false` | Required — do not enable |
| `SYNTHESIS_CONCURRENCY` | `8` | Parallel Gemini partial segments |
| `SYNTHESIS_BATCH_LIMIT` | `8` | Segments per process kick |
| **`SYNTHESIS_STREAM_ENABLED`** | **`true`** | **New in v2.3.12** — stream final merge |
| `SYNTHESIS_MAX_TOKENS` | `5000` | Final Sonnet output cap |
| `SYNTHESIS_PARTIAL_MAX_TOKENS` | `4000` | Partial summary cap |
| `ABSTRACTION_ESCALATION_ENABLED` | `false` | Skip Sonnet re-reads |

**Worker service (unchanged):** `WORKER_DISABLED=true`, scale-to-zero.

## Observability

| Event | When |
|-------|------|
| `synthesis_merge_stream_delta` | First streamed delta from final merge — includes `timeToFirstDeltaMs` |
| `synthesis_merge_complete` | Merge saved — now includes `streamed` and `timeToFirstDeltaMs` when applicable |

## Acceptance criteria (Phase 2)

- Time-to-first visible text during merge (target &lt; 5s on large jobs)
- Final saved result identical to non-streaming path on regression fixtures
- No invalid partial opinion in `job_results` — preview cleared on save or validation failure
