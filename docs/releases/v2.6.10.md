## Changes

- **Haiku thinking count shown:** the OCR comparison page displayed "thinking —" for Claude Haiku 5.5 because Anthropic reports thinking in `output_tokens_details.thinking_tokens` rather than a top-level field. The lab now surfaces that value as `thinking_tokens`.
- **Display only:** Haiku's `output_tokens` already include thinking, and the cost estimate does not add it again. Gemini usage is unchanged.
- **Docs:** `docs/ocr-comparison-lab.md` describes the displayed thinking count.

## Verification and rollout

- `npm test` passed, including a new test built from a real Haiku usage report (2,853 output tokens, 1,700 thinking) that checks the cost is billed once.
- No environment variable change is required. The API service keeps `OCR_COMPARE_ENABLED=true` and `ANTHROPIC_API_KEY`.
