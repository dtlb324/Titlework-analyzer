## Changes

- **Default synthesis model:** `SYNTHESIS_MODEL` and `ABSTRACT_ESCALATION_MODEL` now default to `claude-sonnet-5` (OpenRouter: `anthropic/claude-sonnet-5`). The browser fallback in `public/index.html` matches. `claude-sonnet-4-6` stays on the analyze allowlist so an explicit override still validates.
- **Sonnet 5 request shape:** Anthropic and OpenRouter bodies still send only `model`, `max_tokens`, `system`, and `messages` — no `thinking`, `temperature`, `top_p`, or `top_k` (Sonnet 5 rejects those). Adaptive thinking stays on (no `thinking: {type:"disabled"}`).
- **Token cap:** browser `SYNTHESIS_MAX_TOKENS` is 8000, matching the existing server default.
