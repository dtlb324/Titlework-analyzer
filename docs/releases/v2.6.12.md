## Changes

- **Document accuracy:** for a PDF, the comparison page reads the embedded text in the browser and scores each model's transcribed fields against it. The percent is the share of those fields found in the document. `100%` means every scored field was found.
- **What is scored:** GRANTOR, GRANTEE, DATE EXECUTED, DATE RECORDED, and RECORDING REF always count. A missing identity field is a miss. An illegible or not-applicable value is left out. LEGAL DESC, FRACTION CONVEYED, and RESERVATIONS count only when a model returns a real value. Yes/no judgment fields are not scored.
- **Ranking:** a rank table compares the models on documents that have embedded text and that every model returned. A file drops out of the rank when any model fails. The open file still shows a percent for the models that returned.
- **No text layer:** images and scans with no embedded text have no score. The text is not uploaded. Models still receive only rendered page images.
- **Report:** a finished model's download entry includes `accuracy` with `matched`, `scored`, and `percent` when a score exists.
- **Docs:** `docs/ocr-comparison-lab.md` describes the score.
- **Verification skill:** `.cursor/skills/verify-titlework/` gives a later run a way to launch an isolated server and drive the home page.
