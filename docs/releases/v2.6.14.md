## Changes

All changes are in the isolated OCR comparison lab (`/ocr-compare.html`). Production abstraction and synthesis are unchanged.

### 60 pages per file (#99)

- **Page cap:** each file can now hold up to 60 rendered pages (was 10), on both the server and the browser. The 12 MB per-file byte cap is unchanged.
- **JPEG fallback:** a page stays lossless PNG while it fits its share of the remaining byte budget. Otherwise the same pixels (render scale 2) are re-encoded as JPEG, from quality 0.92 down to 0.45. If nothing fits, the existing 12 MB error is shown.

### More reasoning headroom (#99)

- **Gemini 3.8 Flash:** thinking level `low` → `medium`. The "Current Gemini" baseline still follows server configuration.
- **Shared output limit:** default 8,000 → 16,000 tokens. Thinking tokens count against this limit. `OCR_COMPARE_MAX_TOKENS` now accepts 512–32,000 (was 512–8,192).
- **Streamed Haiku:** Anthropic requires streaming above 8,192 output tokens, so the lab streams Haiku calls above that limit. The streaming path now forwards `effort`, uses the lab's direct Anthropic key check, and keeps input and cache token counts so cost estimates stay correct.

### Per-model effort buttons (#100)

- **Buttons:** each model column has a row of effort buttons at the top. They load from a free metadata request once the password is entered. Click a level to use it in the next comparison.
- **Levels:**
  - Current Gemini: `minimal`/`low`/`medium`/`high`, plus `default` when `GEMINI_THINKING_LEVEL` is unset (sends no thinking level). Baselines on 3.7/3.8 Flash or Pro get no `minimal`.
  - Gemini 3.8 Flash: `low`/`medium`/`high`.
  - Claude Haiku 5.5: `low`/`medium`/`high`/`xhigh`/`max`.
- **Validation:** the server accepts only each model's listed levels. Anything else returns 400 before any provider call. Requests without `efforts` behave as before.
- **Behavior:** buttons are locked while a comparison runs. Columns you haven't clicked follow the server's level. A picked level is kept, or reset with a note if the server stops offering it. Load errors show under the buttons, not in the document status.
- **Reporting:** the chosen level appears in the settings line, each result, and the JSON report (`effort`).

## Verification and rollout

- Full `npm test` passed on Node 22 for both PRs before this metadata commit, and again on the release tree.
- Both PRs were checked with mocked providers only. Real Google and Anthropic calls have not been made, so the first live comparison is the first check that every effort level is accepted and that 60-page uploads fit in practice.
- Medium and higher thinking on long documents uses more tokens and time. The per-call timeout is still 240 seconds.
- No environment variable change is required. `OCR_COMPARE_ENABLED` stays as already configured. `OCR_COMPARE_MAX_TOKENS`, if set, now accepts values up to 32,000.
