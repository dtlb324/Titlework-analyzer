# v2.6.22 — Front-page and results dashboard updates

Patch release covering all commits since v2.6.21, plus release metadata.

## Included changes

### Front page and results dashboard (#135, #136, #137)

- Redesign the front page and add a results dashboard with ownership, defects, chain of title, qualifications, and markdown fallback.
- Repair document intake, queue handling, errors and navigation guards; preserve opinion details and dashboard flows.
- Repair PDF export, result loading and retries, authentication recovery, polling, job controls, mobile table layout, and accessibility.

### OCR comparison lab (#133, #134)

- Add an opt-in OpenRouter provider and allow three configurable OpenRouter models for local comparisons, with effort controls and normalized usage and cost handling.

### Browser audit probes (#142)

- Update retained probes for current UI behavior, preserve original evidence, and add portable checks and regression tests. Keep audit scripts out of the production image.

### Release metadata

- Update the package and root lockfile versions to 2.6.22.

## Rollout

- No database migration is included. OpenRouter lab routing and custom model selection are opt-in.
- Cloud Run deployment is optional and controlled by `DEPLOY_TO_CLOUD_RUN`; the tag workflow runs tests before publishing the GitHub Release.
