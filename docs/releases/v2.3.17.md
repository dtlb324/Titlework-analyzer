# v2.3.17 — Remember access password

Patch release: optional **Remember password on this device** on the access gate so returning users on the same browser do not need to re-enter the shared password every visit.

---

## Highlights

- **Remember password** — checkbox on the access gate; when checked, the password is stored in `localStorage` across browser sessions
- **Session-only default** — unchecked behavior unchanged: password kept in `sessionStorage` for the current tab session only
- **Invalid password cleanup** — wrong password clears both `localStorage` and `sessionStorage` so a bad value is not remembered

---

## UI

### Files

- `public/index.html` — remember-password checkbox, `loadStoredPassword` / `persistPassword` / `clearStoredPassword` helpers
- `test/jobs.test.js` — coverage for remember-password persistence
