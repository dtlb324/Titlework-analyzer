# v2.6.19 — Release workflow deploys the amd64 image digest

Patch release covering every commit since v2.6.18: PR #126 and the release metadata commit.

## Included changes

- Resolve the `linux/amd64` platform digest when the image push is an OCI image index, then deploy and verify that digest. v2.6.18 failed `Verify production release` with "Deployed digest did not match expected" because Cloud Run reports the amd64 child digest while the build recorded the index digest (#126). Adds `scripts/resolve-image-digest.mjs`, release tests, and a README update.
- The release metadata commit updates `package.json`, both root lockfile versions, and these notes to 2.6.19.

## Rollout

- No environment variable change is required.
- No application code changed; this release exercises the corrected release workflow end to end.
- The release workflow deploys the worker and API from one immutable image digest, verifies version and service parity, and creates the GitHub Release. The published release lists the complete commit range.
