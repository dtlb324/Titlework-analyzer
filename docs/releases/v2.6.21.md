# v2.6.21 — Gemini 4 Hydrogen in the OCR comparison lab

Patch release covering every commit since v2.6.20: PR #130 (opt-in Cloud Run deployment), PR #131 (Gemini 4 Hydrogen in the OCR lab), and the release metadata commit.

## Included changes

### OCR comparison lab (#131)

- **Gemini 4 Hydrogen replaces Gemini 3.8 Flash** as the lab's second column (`gemini-4-hydrogen`). Effort buttons are `low`, `medium`, `high`, `xhigh`, defaulting to `medium`; `minimal`, `default`, and `max` are rejected.
- **Cost:** Hydrogen is estimated at $1.50 / MTok input and $7.50 / MTok output, with thinking billed as output. The 3.8 Flash rates remain for the Current Gemini column when `ABSTRACT_MODEL` points at it.
- **Model names before a run:** column headings, effort-group labels, and the differences table header show each model's label and id as soon as metadata loads, instead of Baseline/Candidate/Challenger.
- **Keyboard focus:** effort buttons update in place, so focus stays on the chosen level, and a click during a metadata reload is kept.

### Gemini request handling (#131)

- Gemini 4 models now send `thinkingConfig.thinkingLevel`. Previously any `gemini-4*` model fell into the Gemini 2.5 path and was sent `thinkingBudget: 0`.
- `xhigh` is accepted only for `gemini-4-hydrogen` (and its `-preview`/dated variants); `minimal` is rejected for all Gemini 4 models; `thinkingBudget` is never sent to Gemini 4.
- Gemini 3 and 2.5 request bodies are unchanged.
- `scripts/compare-final-opinion.mjs` resolves Gemini 4 thinking levels without a budget, exits 1 on an unsupported level, and lists `xhigh` in `--help`.

### Release workflow (#130)

- Cloud Run deployment is opt-in through the `DEPLOY_TO_CLOUD_RUN` repository variable. Without it, a tag validates the version and runs the tests but does not build or deploy.

### Release metadata

- `package.json`, both root lockfile versions, and these notes move to 2.6.21.

## Rollout

- No schema change. No environment variable change is required for the lab; the existing `GEMINI_API_KEY` serves Hydrogen.
- `DEPLOY_TO_CLOUD_RUN` is not set on this repository, so this tag does not deploy to Cloud Run. The live service keeps running the previous revision until a deploy is run.
- Hydrogen was verified with stubbed providers and headless Chromium only; no live Gemini call has been made against it.
