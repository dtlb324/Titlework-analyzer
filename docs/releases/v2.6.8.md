## Changes

- **Third model in the OCR lab:** `/ocr-compare.html` now compares the configured Gemini baseline, `gemini-3.8-flash`, and `claude-haiku-5-5` on the same rendered page images with the same prompt and output-token limit. Haiku runs through the direct Anthropic API (never OpenRouter) at `output_config.effort: low`, with adaptive thinking.
- **Isolated failures:** a missing `ANTHROPIC_API_KEY` fails only the Haiku column; the Gemini results are still returned.
- **Cost estimates:** Haiku is estimated at $0.10 input / $0.50 output per million tokens up to 100K prompt tokens ($0.50 / $2.50 above), with cache write and read rates when reported.
- **Null-cost fix:** Gemini responses that omit `thoughtsTokenCount` are treated as zero thinking tokens, so the estimate is no longer `null`. Missing input or output counts still produce no estimate.
- **UI:** third output panel, a Challenger column in the differences table, and a responsive layout. Page images are now disclosed as sent to both Google and Anthropic.
- **Production unchanged:** `buildMessagesRequestBody` gains an optional `effort` that production calls never set.

## Verification and rollout

- `npm test` passed, including new tests for the Haiku request shape, cost tiers, the missing-key case, and the null-thinking cost.
- The page was loaded in headless Chrome with a stub provider and a real 10-page PDF: three columns, no console errors, no horizontal scroll at 1500, 1000, and 600 px.
- No live Anthropic call was made before release, so `output_config.effort` and image handling on `claude-haiku-5-5` are untested against the real service.
- The API service keeps `OCR_COMPARE_ENABLED=true` and needs `ANTHROPIC_API_KEY`. Each comparison now makes three billable calls.
