## Security

- **form-data CVE patched (GHSA-hmw2-7cc7-3qxx, high):** 2.5.4 → 2.5.6, pulled in via `@google-cloud/storage → retry-request`. Clears the only high-severity advisory in the dependency tree.
- **Server workflow endpoints now verify the password themselves:** `requireServerAbstractionPassword` previously trusted the upstream route guard; it now runs its own constant-time compare of `x-app-password` and **fails closed with 401 when `APP_PASSWORD` is unset**. Protects abstraction/synthesis start/process, chunk retry, retry-failed, follow-up, and abstracts — the endpoints that trigger billable model calls — against guard-reorder regressions. No change for legitimate authenticated flows; metadata routes keep passwordless local-dev mode.

## Bug fixes

- **Stale title opinion after retry-failed:** requeueing failed chunks (`POST /api/jobs/:id/retry-failed`) now clears any previously saved job result. Previously a `partial_failed` job kept serving the old opinion — synthesized from pre-retry abstracts — while the job re-ran. Found via bug hunt with a RED-gate regression test that fails on the old code.
