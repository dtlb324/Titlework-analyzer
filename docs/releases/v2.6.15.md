## OCR comparison repairs

- Treat Anthropic streaming error events and incomplete responses as independent model failures rather than successful partial text or provisional cost estimates. Preserve valid completed output and LF/CRLF streaming frames.
- Apply the 12 MB rendered-image cap to the whole PDF. Keep every page lossless PNG when the combined size fits. For oversized totals, compress the largest pages with the existing JPEG quality ladder at unchanged render scale.
- Validate baseline effort capabilities and configured defaults before any inference. Gemini 3.1 Flash-Lite Image offers only `minimal` and `high`, plus provider `default` when unset. Invalid configured levels fail closed.
- Allow explicit comparisons of already prepared files after changing effort, without selecting or rendering them again. Explicit reruns make new billable calls and replace previous results; no automatic retries are added.
- Keep metadata errors visible through file selection, discard stale credential responses, and preserve still-supported effort choices after valid refreshes.

## State-aware reader cleanup

- Cancel only an open response abandoned by parser or callback failure, using the original failure as the cancellation reason.
- Release the reader lock on every exit. Already exhausted or transport-failed streams are not cancelled again.
- Do not let a throwing, rejected, delayed, or stalled cleanup replace the original result/error or delay failure reporting.

The Anthropic parser is shared by the OCR lab and production Claude streaming callers. This release does not change model defaults, page/byte caps, output-token limits, timeout limits, dependencies, or synthesis logic. The many-image provider-dimension compatibility concern remains unverified and outside these repairs.
