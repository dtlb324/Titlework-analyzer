## Changes

- **Static files:** `safePublicPath` rejects `..` after decoding, so a request such as `/..%2f...` cannot leave the public directory by sharing its prefix.
- **Job names:** titles in the rename field are attribute-escaped. A successful password check clears the password input.
- **Object storage:** a chunk patch that sets a blob URL must name a key under `jobs/{jobId}/chunks/{chunkId}/` and pass `validateObjectRef`. `readObject` stays on a key under `jobs/{jobId}/` and on `GCS_BUCKET` when that is set. Storage URLs reject userinfo, non-443 ports, dot segments, and lookalike hosts.
- **Analyze proxy:** model ids must match `^[A-Za-z0-9._-]{1,80}$`, so a slash id is not forwarded to OpenRouter.
- **Production password:** `requireJobPassword` and the analyze handler return 401 when `APP_PASSWORD` is unset in production (`NODE_ENV=production` or `K_SERVICE`). Local runs with no password still work.
- **Request ids and drain errors:** client `X-Request-Id` values are kept only when they match a short token. Drain failures return `Drain failed.` and log the reason on the server. `secureCompare` uses `crypto.timingSafeEqual`.
- **Runtime:** the image runs as `USER node`. jsPDF and pdf-lib are pinned with SRI. The page CSP adds `base-uri`, `object-src`, and `form-action`.

## Tests

- `test/security-hardening.test.js`: public-directory prefix escape, production fail-closed when `APP_PASSWORD` is unset, slash model ids, and reflected request ids
- Storage tests reject a blob URL that retargets another bucket or object
- Job rename escapes HTML in the name field
- Drain failures omit the internal error text
- Full suite green
