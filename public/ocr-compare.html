Up to ten documents. The same page images for every model. Three independent model outputs per document.

Compare a document

PDFs are rendered locally into page images; hidden text layers are not sent. Images are decoded and validated locally. This isolated test does not create jobs or save documents to application storage. Model requests are billable, and page images are sent to both Google and Anthropic.

All three models use the same max output token limit, shown with their effective server settings. Production escalation and batching are excluded; this is an isolated OCR comparison, not the production title-analysis workflow.

Not saved in browser storage. Provider API keys stay on the server.
Each file is compared on its own: up to 10 pages and 12 MB of decoded image bytes after rendering per file. Each file makes three billable model calls.
